# Hostinger Deployment Guide - RushXO

Panduan deploy RushXO taxi platform ke Hostinger dengan subdomain `dashboard.rushxo.com`.

---

## 📋 Prerequisites

- ✅ Hostinger hosting plan aktif (Business atau lebih tinggi)
- ✅ Subdomain `dashboard.rushxo.com` sudah dibuat dengan folder `/public_html/dashboard/public`
- ✅ SSL certificate aktif (Lifetime SSL)
- ✅ MySQL database sudah dibuat
- ✅ SSH access aktif (recommended untuk easy deployment)

## 📦 Step 2: Upload Laravel Files

### Opsi A: Via Git (Recommended) ⭐

Aktifkan **SSH Access** di hPanel → **Advanced** → **SSH Access** → Enable.

```bash
# SSH ke Hostinger
ssh u562106935@rushxo.com -p 65002

# Navigate ke parent folder
cd ~/domains/rushxo.com/public_html/

# Hapus folder dashboard default (jika ada)
rm -rf dashboard

# Clone repo
git clone https://github.com/s4rt4/taxi-aggregator.git dashboard
cd dashboard

# Install composer dependencies
composer install --no-dev --optimize-autoloader

# Copy .env.example ke .env
cp .env.example .env
nano .env   # Edit sesuai Step 3 di bawah

# Generate app key
php artisan key:generate

# Run migrations + seed
php artisan migrate --force --seed

# Create storage symlink
php artisan storage:link

# Cache for production
php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan event:cache
```

### Opsi B: Via File Manager (No SSH)

1. Download build `.zip` dari GitHub: `https://github.com/s4rt4/taxi-aggregator/archive/main.zip`
2. Lokal: extract, jalankan `composer install --no-dev --optimize-autoloader` + `npm install && npm run build`
3. Zip ulang seluruh folder (kecuali `node_modules/`)
4. Upload via File Manager ke `/public_html/dashboard/`
5. Extract di server
6. Via File Manager terminal: `php artisan key:generate`, `migrate --seed`, dll

## 📧 Step 5: Register Stripe Webhook

1. Login [Stripe Dashboard](https://dashboard.stripe.com)
2. **Developers** → **Webhooks** → **Add endpoint**
3. Endpoint URL: `https://dashboard.rushxo.com/webhooks/stripe`
4. Events to send:
   - `checkout.session.completed`
   - `payment_intent.payment_failed`
   - `charge.refunded`
5. **Add endpoint**
6. Copy **Signing secret** (`whsec_...`) → paste ke `STRIPE_WEBHOOK_SECRET` di `.env`
7. Re-run: `php artisan config:cache`

## 🗺️ Step 6: Restrict Google Maps API Key

Supaya API key tidak disalahgunakan orang lain:

1. Login [Google Cloud Console](https://console.cloud.google.com)
2. **APIs & Services** → **Credentials**
3. Click API key kamu
4. **Application restrictions** → HTTP referrers:
   - `https://dashboard.rushxo.com/*`
   - `https://rushxo.com/*` (kalau perlu)
5. **API restrictions** → Restrict to:
   - Places API
   - Maps JavaScript API
   - Distance Matrix API
6. Save

## 🔄 Step 8: Setup Queue Worker (Optional but Recommended)

Tanpa queue worker, email/SMS notifications tetap jalan (jadi sync), tapi lebih lambat.

Kalau mau async (lebih cepat):

1. hPanel → **Cron Jobs** → add job:
   - Command: `cd /home/u562106935/domains/rushxo.com/public_html/dashboard && php artisan queue:work --stop-when-empty --max-time=60`
   - Every: `* * * * *` (every minute)

Ini akan process queue jobs setiap menit (max 60 detik per run).

## 🚨 Troubleshooting

### Error 500 (Server Error)
```bash
# Cek log terbaru
tail -n 50 storage/logs/laravel.log

# Common fixes:
php artisan config:clear
php artisan cache:clear
php artisan view:clear
chmod -R 775 storage bootstrap/cache
```

### "The stream or file could not be opened"
Permission masalah di storage:
```bash
chmod -R 775 storage
chown -R u562106935:u562106935 storage
```

### CSS/JS 404 Not Found
Build assets belum ter-upload atau path salah:
```bash
# Di local:
npm run build

# Upload seluruh folder public/build/ ke server
```

### DNS belum propagasi
Test dengan:
```bash
nslookup dashboard.rushxo.com
```
Tunggu hingga 1 jam, atau test via https://dnschecker.org

### Database connection error
Double-check `.env`:
- DB_HOST, DB_DATABASE, DB_USERNAME, DB_PASSWORD
- Database user punya privilege ke database (di hPanel)
